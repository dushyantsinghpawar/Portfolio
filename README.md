# Portfolio

Dushyant Singh Pawar's personal site: dushyantsinghpawar.github.io/Portfolio

A full-stack engineer's portfolio covering experience across React, TypeScript, FastAPI, Node.js, and AWS, plus a handful of AI-powered side projects (RAG retrieval, computer vision, LLM tooling). Built to show the work, not just talk about it.

## Stack

Static HTML, CSS, and vanilla JS. No build step, no framework, no dependencies to install. Just open `index.html` or serve the folder with anything that handles static files.

```bash
python3 -m http.server 8000
# or
npx serve .
```

## Structure

- `index.html` - all page content and inline scripts
- `styles.css` - all styling
- `images/` - portraits, project screenshots/demos, and company logos
- `thankyou.html` - redirect page after a contact form submission (FormSubmit)

## Deployment

Hosted on GitHub Pages, deployed straight from `main`.
