Featured Projects

Featured Project

MedKids OrderUp AI

MedKids OrderUp AI helps parents find recipes that are actually safe for their kids to eat. Parents set up an allergen profile for each child, and the app filters out anything that touches those allergens before a single recipe shows up, then ranks what's left by that kid's nutrition goals. I led the team that built it and did most of the hands-on engineering myself, across the frontend, both backend services, and the infrastructure running all three.

React / TypeScript client Node / Express API FastAPI recommendation service MongoDB Atlas

The recommendation service sits behind its own API-key boundary, isolated from the main API.

My Role

Primary engineer and de facto DevOps lead on a 5-person team: the backend split, a frontend rebuild from a Figma handoff, the AI service, auth, and the deploy pipeline.

Key Decisions

The allergen engine hard-excludes any recipe with a matching allergen instead of scoring it lower, so nothing borderline slips through. The recommendation logic lives in its own Python service, since the NLP tooling it needs doesn't have a good Node equivalent.

Challenges

Allergen names show up inconsistently across recipe sources: peanut, peanuts, groundnut. I built a synonym-normalization layer shared between the TypeScript and Python sides, with a CI check that fails the build if the two drift apart. I also traced a flaky test suite to every test spinning up its own in-memory database, and fixed it with one shared instance and per-file isolation.

Results

Backend coverage landed around 92% of lines and 84% of branches, with the AI service at 100%. Deployed as three separate services across Render and Vercel, with GitHub Actions gating every deploy on the full suite passing.
